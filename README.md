## Описание

**«Управление семейными финансами»** — это десктопное приложение для учёта личных финансов, разработанное в рамках производственной практики на предприятии. Приложение позволяет пользователям систематизировать доходы и расходы, анализировать финансовые привычки и контролировать бюджет в удобной визуальной форме.

## Установка
1. Убедитесь, что на компьютере установлена IntelliJ IDEA Community Edition 2024.2.2

2. Скачайте файлы приложения:
FamilyBudgetApp.java

sqlite-jdbc.jar (драйвер базы данных)

4. Скомпилируйте приложение

5. Запустите приложение

6. При первом запуске автоматически создастся файл базы данных family_budget_v3.db
# Использование
 Управление семейными финансами — это мощное и гибкое приложение для личного и семейного финансового учёта, построенное на работе с таблицами внутри коллекций. Оно предоставляет удобный инструмент для контроля доходов, расходов и планирования.
# Разработка
Данный проект не нуждается в посторонней помощи для разработки, так как он создаётся в рамках производственной практики, что подразумевает его разработку одним человеком
